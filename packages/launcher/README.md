# kilnry

The small cross-platform launcher for [Kilnry](https://github.com/ApoorvDixitt/kilnry), a local-first AI media studio.

## Start

```sh
npx -y kilnry
```

## Diagnose

```sh
npx -y kilnry doctor
npx -y kilnry doctor --json
```

The launcher binds the application to `127.0.0.1`, verifies downloaded standalone builds before running them, and keeps media outside the npm package in the Library folder you choose.
