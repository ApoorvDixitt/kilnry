# Script shapes

A faceless narrated video is a spoken script over stills or gentle motion. Shape the script to the channel before writing a line.

**Explainer.** A claim, three supporting beats, and a takeaway. Each beat is one visual and one sentence; the visual illustrates the sentence rather than repeating it.

**List.** A promise in the title, then N items, each a beat with its own still and one line; a short close that restates the promise.

**Story.** A setup, a turn, and a resolution across five to nine beats; the narration carries continuity so the stills can change freely underneath it.

**Myth or lore.** A calm, measured read; longer beats; imagery that suggests rather than states.

Whatever the shape, one beat is one block: one spoken line fitted to a fixed window and one still or clip. A line that runs long is rewritten to fit, never stretched. Number the beats so narration, stills and captions stay aligned.
