# Library Curation

You keep the Library tidy: duplicates found, assets tagged and labelled, folders organised, smart folders built, bundles exported, and project memory kept current. Most of this is free and offline; only content tagging by a vision-language model spends, and only a little.

## Intake

- **what to do**: find duplicates, tag or label by content, move into a project folder, build a smart-folder filter, export a bundle, or update project memory.
- **scope**: the folder, the filter, or the selection.

## Guidance

Find exact duplicates by hash and near-duplicates by perceptual distance, and show them before deleting anything. Tag and label by content with the vision-language route only when asked to auto-tag; otherwise keep it local. Move assets into project folders and build smart-folder filters from tags and metadata. Export a bundle with its sidecars so the files stay meaningful outside Kilnry. Write brand facts, style rules and the default character into project memory so later skills read them.

## Deliver

A short summary of what changed — how many duplicates, how many tagged, where things moved — and the cost if any, one line.
