# GPT Image (image, image edit)

An image model that follows written instructions literally, including layout and text.

- It renders legible text — say the exact words and where they sit if the image needs them.
- Describe composition in plain terms (subject centred, product lower third, logo top-right).
- For an edit, state the change and what to preserve; it keeps unmentioned areas.
- Give the aspect ratio and any palette explicitly.
- If a look drifts, tighten the instruction rather than adding style words.
