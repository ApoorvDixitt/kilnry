# Veo (text-to-video)

A high-fidelity motion model that follows detailed direction and can carry audio.

- Write like a shot list line: subject, action, setting, camera, light — in that order.
- It honours specific camera language (dolly, crane, handheld); name exactly one per clip.
- When audio is wanted, describe the ambient sound or dialogue intent briefly; otherwise ask for none.
- Keep continuity cues explicit if the clip is part of a sequence (same wardrobe, same location).
- Avoid stacking many subjects; Veo is sharpest with one clear focus.
