# Wan (text-to-video, image-to-video)

An efficient motion model good for clean, contained shots.

- Keep the scene simple: one subject, one background, one motion.
- Name the camera move plainly (static, slow push, gentle pan); Wan holds steady shots well.
- For image-to-video, prompt only the motion; let the reference carry the look.
- Short beats read best — five to eight seconds.
- Avoid crowds, dense text, and hard style shifts.
