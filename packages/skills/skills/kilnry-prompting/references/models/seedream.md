# Seedream (image, image edit)

A high-resolution image model strong on style and reference consistency.

- Lead with the look — the style, the palette, the light — then the subject and framing.
- It holds a supplied style reference well; pass one to lock a series to one look.
- Ask for the resolution and aspect ratio; Seedream reaches high resolutions natively.
- For an edit, name the reference and the single change.
- Avoid contradictory style cues; pick one aesthetic and commit.
