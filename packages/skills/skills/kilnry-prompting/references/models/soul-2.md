# Soul 2 (image)

A portrait and character image model tuned for believable people.

- Describe the person plainly: build, hair, wardrobe, expression, and the setting.
- Name the light for the face (soft window light, warm key, overcast) — it drives realism.
- Frame the shot (headshot, waist-up, full length) and the lens feel.
- For a recurring person, use the Character `@mention` so the resolver supplies the anchors; do not re-describe from scratch.
- Negative-direction the usual portrait failures: no warped hands, no extra fingers, no plastic skin.
