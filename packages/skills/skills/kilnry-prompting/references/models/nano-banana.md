# Nano Banana (image, image edit)

A fast image and edit model that follows reference images closely.

- For a fresh image: subject, setting, light, framing, in one tight paragraph.
- For an edit: name the reference and describe only the change (swap the background, change the shirt to red); leave the rest unsaid so it stays.
- It respects supplied references strongly — supply a clean one and keep the edit instruction minimal.
- Ask for the aspect ratio explicitly.
- Avoid piling on adjectives; one clear look beats five competing ones.
