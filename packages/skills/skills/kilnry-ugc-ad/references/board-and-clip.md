# Boards and clips

A board is one storyboard sheet: a row of vertical panels, each a distinct shot of the same scene, varying shot size and angle — wide, medium, close, detail, and an over-shoulder only when a person is in frame. One board covers about fifteen seconds; a longer ad uses one board per fifteen seconds and continues the previous board's last frame so the action reads as one take.

Keep the product identical across panels. It appears once per panel where the script needs it, label facing camera, at a scale true to a hand. Do not reintroduce or duplicate it. When no person is in the scene, use hands and point-of-view framing only.

A clip animates one board's beat into motion. Each clip runs the segment's length, references the cleaned board, and carries the creator and product as references so the face, wardrobe and packaging do not drift. Render one clip per board, then assemble them in order, cut to length, and caption.

Regenerate a single panel or clip when it drifts rather than re-rendering the set; a refine pass fixes light and edges only and never reshapes the product.
