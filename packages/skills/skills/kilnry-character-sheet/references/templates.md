# Sheet templates

The character sheet is built from the anchor in four passes, each a prompt template the "Build sheet" button and the workflow share so the wording is identical.

**Turnaround rows.** Two row sheets cover the head from five angles: front, three-quarter left, left profile, back on the first row; three-quarter right and right profile on the second. Same face, hair and wardrobe in every panel; neutral expression; even light; plain backdrop.

**Full body.** One head-to-toe shot in a relaxed standing pose, the same wardrobe, so proportions and footwear are on record.

**Expression grid.** A three-by-three grid of the same face running through nine expressions — neutral, smile, laugh, surprise, doubt, focus, joy, calm, and a soft frown — identical framing per cell.

Cut every panel into its own reference file locally, trim to the subject, and register them on the Character. Pause for approval after the turnaround so a wrong likeness is caught before the body and grid are spent.
