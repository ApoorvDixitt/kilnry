# Roadmap

Kilnry's vision is a dependable local studio in which one creator can generate, organise, reuse, automate, and inspect AI media without surrendering files, keys, or spending control to a hosted service.

## Version 1

Version 1 covers the local web studio, Library and sidecars, provider routing and budgets, jobs, Characters and reusable Elements and Voices, Presets, Workflows, Chat, twenty MCP tools, local packaging, Docker, and launch documentation.

## Explicitly outside Version 1

Community hosting and galleries, cloud storage and sync, internet-exposed MCP with OAuth, team workspaces, YouTube and Instagram publishing, a timeline motion editor, arbitrary skill scripts, a paid plugin marketplace, mobile applications, and Kilnry-hosted accounts or provider proxies are outside Version 1. They require separate product, security, cost, and legal decisions.

P2 features documented for V1.x remain optional follow-up work unless promoted by a recorded decision.
